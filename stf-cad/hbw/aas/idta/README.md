# IDTA submodel templates

The JSON files here are the official submodel templates of the Industrial Digital Twin Association,
unchanged, from <https://github.com/admin-shell-io/submodel-templates> (`published/`), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `aas/build.py` instantiates them.

| File | Template | Version |
|---|---|---|
| Digital_nameplate.json | IDTA 02006 Digital Nameplate for Industrial Equipment | 3.0 |
| Technical_Data.json | IDTA 02003 Generic Frame for Technical Data | 2.0 |
| Hierarchical_Structures_enabling_Bills_of_Material.json | IDTA 02011 Hierarchical Structures enabling Bills of Material | 1.1 |
| Handover_Documentation.json | IDTA 02004 Handover Documentation (VDI 2770) | 2.0 |
| Carbon_Footprint.json | IDTA 02023 Carbon Footprint | 1.0 |
| Time_Series_Data.json | IDTA 02008 Time Series Data | 1.1 |
| Provision_of_3D_Models.json | IDTA 02026 Provision of 3D Models | 1.0 |
| Artificial_Intelligence_Model_Nameplate.json | IDTA 02060 AI Model Nameplate | 1.0 |
