# One simulated month of production (STF, Upgrade 7 machine)

Generated by `stf-cad/hbw/month.py` (`STF_VARIANT=up7 python3 month.py`, seed 20260901).
Simulated from the models, not measured. Every rate, life, repair time and disturbance is assumed; see `meta.assumed` in `month.json`.

| file | one row per | columns |
|---|---|---|
| `orders.csv` | order (12-cookie batch) | time, day, shift, dur (s), good, scrap, returned, temp (°C) |
| `sensors.csv` | order × component | time, component, observed (s or ratio), ewma_r, health_index (0-100), rul_shifts |
| `raw.csv` | order | time, hall temp, A4 mV per flavour, HBW current (A), compressor duty |
| `events.csv` | event | time, kind (fault / warning / work order / maintenance / failure), what, component, alarm code, lost s, down h |
| `daily.csv` | day | orders, baked, good, scrap, run h, faults, maintenance, failures, A, P, Q, OEE |
| `fsm.csv` | unit | hours in RUN, HELD, READY, FAULT, ESTOP, MAINT |
| `month.json` | - | all of the above plus the counterfactual month, the two saves and the insights (the dashboard reads this) |
